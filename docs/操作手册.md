# 药品智能查询系统 - 从零开始操作手册

> 本手册写给完全不懂编程的人，每一步都写得很细，照着做就行。

---

## 一、这个项目是干什么的？

简单说：这是一个**手机上查药品信息的APP**。

- 你在手机上输入药品名字（比如"布洛芬"），点搜索
- 手机把请求发给电脑上运行的后端程序
- 后端去数据库里查药品信息，返回给手机
- 手机上显示药品列表，点进去能看详情（价格、保质期、怎么吃、治什么）

整个系统由 **3 部分**组成，缺一不可：

| 部分 | 作用 | 运行在 | 端口 |
|------|------|--------|------|
| MySQL 数据库 | 存药品数据 | 电脑 | 3308 |
| 后端程序（Java） | 处理请求、查数据库 | 电脑 | 8082 |
| 前端APP（HarmonyOS） | 手机界面，用户操作 | 手机模拟器 | - |

另外还有一个**可选的图片服务**（Tomcat，端口8085），用来显示药品图片。如果不启动，APP能跑但图片加载不出来。

## 二、环境准备（需要装哪些软件）

在跑项目之前，你电脑上需要装以下软件。如果已经装过了，可以跳过对应步骤。

### 2.1 安装 JDK 8（Java开发工具包）

后端是用 Java 写的，必须装 JDK 才能运行。

1. 打开浏览器，搜索 "JDK 8 下载"，去 Oracle 官网或国内镜像站下载 Windows 版本
2. 双击安装包，一路点"下一步"，记住安装路径（默认一般是 `C:\Program Files\Java\jdk1.8.0_xxx`）
3. 配置环境变量：
   - 右键"此电脑" → 属性 → 高级系统设置 → 环境变量
   - 在"系统变量"里点"新建"：
     - 变量名：`JAVA_HOME`
     - 变量值：你的JDK安装路径（比如 `C:\Program Files\Java\jdk1.8.0_202`）
   - 找到系统变量里的 `Path`，点"编辑" → "新建"，输入 `%JAVA_HOME%\bin`
   - 一路点"确定"保存
4. **验证是否成功**：按 `Win + R`，输入 `cmd` 回车，在黑窗口里输入：
   ```
   java -version
   ```
   如果显示 `java version "1.8.0_xxx"` 就说明装好了。

### 2.2 安装 Maven（Java项目管理工具）

Maven 用来下载后端依赖的库、编译和打包项目。

1. 搜索 "Maven 下载"，去官网下载二进制压缩包（`apache-maven-3.x.x-bin.zip`）
2. 解压到一个没有中文和空格的路径，比如 `D:\tools\apache-maven-3.6.1`
   - 本项目的 `archive/tools/apache-maven-3.6.1` 里已经带了一个，可以直接用
3. 配置环境变量：
   - 系统变量新建：`MAVEN_HOME` = `D:\tools\apache-maven-3.6.1`（你的实际路径）
   - Path 里新建：`%MAVEN_HOME%\bin`
4. **验证**：打开 cmd，输入：
   ```
   mvn -v
   ```
   显示版本号就成功了。

### 2.3 安装 MySQL 5.x（数据库）

项目用的是 MySQL 5.x 版本（驱动是 5.1.14），**不要装 MySQL 8.x**，否则可能连不上。

1. 搜索 "MySQL 5.7 下载"，下载 Windows 安装版（`mysql-installer-community-5.7.x.msi`）
2. 双击安装，选择 "Custom" 或 "Developer Default"
3. 安装过程中注意以下设置：
   - **端口**：默认是 3306，但本项目用的是 **3308**。你可以：
     - 方案A（推荐）：安装时把端口改成 3308，这样不用改项目配置
     - 方案B：装默认的 3306，后面改项目配置文件里的端口
   - **root 密码**：设置为 `123`（项目默认配置就是这个），如果设了别的密码后面要改配置
   - 勾选 "Configure MySQL Server as a Windows Service"，让它开机自启
4. 安装完成后，**验证**：打开 cmd，输入：
   ```
   mysql -u root -p
   ```
   输入密码 `123`，能进入 `mysql>` 提示符就成功了。输入 `exit` 退出。

> **注意**：如果你装的 MySQL 端口不是 3308，或者 root 密码不是 123，需要修改后端配置文件，见第四章。

### 2.4 安装 DevEco Studio（鸿蒙开发工具）

前端是 HarmonyOS（鸿蒙）APP，需要用华为的 DevEco Studio 打开和运行。

1. 搜索 "DevEco Studio 下载"，去华为开发者官网下载
2. 本项目用的是 **API 5.1.1(19)**，建议下载支持该版本的 DevEco Studio（4.0以上版本）
3. 双击安装，一路下一步
4. 首次启动会提示安装 SDK，按照提示安装 HarmonyOS SDK（包含模拟器）
5. 安装完成后，需要配置一个模拟器：
   - 打开 DevEco Studio
   - 顶部菜单 Tools → Device Manager
   - 点 "+ New Device"，选一个手机型号（比如 Phone → Mate 60）
   - 点 Next → Finish，等待模拟器镜像下载完成

### 2.5 安装 Tomcat（可选，用于显示药品图片）

如果不装，APP能正常搜索和查看文字信息，但药品图片显示不出来。

1. 本项目的 `archive/tools/apache-tomcat-8.5.65` 里已经带了一个 Tomcat
2. 把它复制到一个短路径，比如 `D:\tools\apache-tomcat-8085`
3. 修改端口为 8085（见第六章）

## 三、初始化数据库

数据库需要手动创建库、建表、导入数据。

### 3.1 创建数据库

1. 打开 cmd，输入以下命令登录 MySQL：
   ```
   mysql -u root -p
   ```
   输入密码 `123` 回车。

2. 进入 `mysql>` 后，输入以下命令创建数据库（注意分号不能少）：
   ```sql
   CREATE DATABASE medicinesystem DEFAULT CHARACTER SET utf8;
   ```
   显示 `Query OK` 就成功了。

3. 输入 `exit` 退出 MySQL。

### 3.2 创建数据表并导入数据

项目的 `docs/数据库.txt` 里有22条药品的 INSERT 语句，但**没有建表语句**，需要先建表。

1. 用记事本打开 `docs/数据库.txt`，全选复制里面的所有内容
2. 回到 cmd，登录 MySQL 后，先切换到刚创建的数据库：
   ```sql
   USE medicinesystem;
   ```
3. 先执行建表语句（复制下面这段，粘贴到 cmd 里回车）：
   ```sql
   CREATE TABLE medicine (
     mid VARCHAR(50) PRIMARY KEY COMMENT '药品ID',
     mname VARCHAR(100) COMMENT '药品名称',
     price DOUBLE COMMENT '单价',
     valid INT COMMENT '保质期(月)',
     eatNum VARCHAR(200) COMMENT '用法用量',
     handle VARCHAR(500) COMMENT '药效说明',
     mimage VARCHAR(500) COMMENT '图片地址'
   ) ENGINE=InnoDB DEFAULT CHARSET=utf8;
   ```
   显示 `Query OK` 就建表成功了。

4. 然后把 `docs/数据库.txt` 里的所有 INSERT 语句复制粘贴到 cmd 里执行（一条一条或全选粘贴都行）。
   - 你会看到一连串 `Query OK, 1 row affected`
   - 全部执行完后，输入以下命令验证数据是否导入成功：
   ```sql
   SELECT COUNT(*) FROM medicine;
   ```
   显示 `22` 就说明22条数据都导入成功了。

5. 输入 `exit` 退出。

> **小技巧**：也可以用 Navicat、SQLyog 等图形化工具来操作数据库，更直观。但 cmd 方式不需要额外装软件。

## 四、启动后端服务

### 4.1 检查/修改配置文件

用记事本打开后端配置文件：
```
backend/src/main/resources/application.properties
```

重点看这几行：
```properties
server.port=8082                                    # 后端端口，不用改
server.servlet.context-path=/med                    # 访问前缀，不用改
spring.datasource.username=root                     # 数据库用户名
spring.datasource.password=123                      # 数据库密码
spring.datasource.url=jdbc:mysql://127.0.0.1:3308/medicinesystem?...
```

**如果你的 MySQL 不是 3308 端口，或者 root 密码不是 123**，把上面对应的值改成你自己的，保存文件。

### 4.2 下载依赖并编译

1. 打开 cmd，进入后端项目目录：
   ```
   cd /d D:\lg\project\archive\medicine-query-system\backend
   ```
   （把路径换成你项目的实际路径）

2. 执行 Maven 编译命令：
   ```
   mvn clean compile
   ```
   - 第一次运行会下载很多依赖包，需要等几分钟（取决于网速）
   - 看到 `BUILD SUCCESS` 就说明编译成功了
   - 如果报错 `mvn 不是内部命令`，说明 Maven 环境变量没配好，回到 2.2 检查

### 4.3 启动后端

在 cmd 里（确保还在 backend 目录下），执行：
```
mvn spring-boot:run
```

等待启动，看到类似下面的信息就说明启动成功了：
```
Started MedIdentifyApplication in X.XXX seconds
```

**不要关闭这个 cmd 窗口**，后端需要一直运行着。

### 4.4 验证后端是否正常

打开浏览器，访问以下地址：
```
http://localhost:8082/med/selectMedByName?mname=Paracetamol
```

如果浏览器显示一段 JSON，里面有 `"status":true` 和药品信息，就说明后端和数据库都正常了。

如果显示 `"status":false`，看看 message 里的错误信息：
- "请输入药品名！" → 地址里 mname 没传值
- "无此相关药品！" → 数据库里没有这个药名，换一个试试（比如 Ibuprofen、Aspirin）
- 连接超时/拒绝 → MySQL 没启动，或者端口/密码不对

## 五、启动图片服务（可选）

药品图片存在 `http://localhost:8085/medicineImages/` 下，需要一个 Tomcat 在 8085 端口提供服务。

### 5.1 配置 Tomcat 端口

1. 进入 Tomcat 目录：`archive/tools/apache-tomcat-8.5.65/conf`
2. 用记事本打开 `server.xml`
3. 找到这一行（大概在第70行左右）：
   ```xml
   <Connector port="8080" protocol="HTTP/1.1" ...
   ```
4. 把 `8080` 改成 `8085`，保存

### 5.2 准备图片资源

1. 在 Tomcat 的 `webapps` 目录下新建一个文件夹，命名为 `medicineImages`
2. 把药品图片放进去。图片文件名要和数据库里 `mimage` 字段对应，比如：
   - `Paracetamol.png`
   - `Ibuprofen.png`
   - `Aspirin.png`
   - 等等（共22种药，对应22张图）

> **注意**：如果没有药品图片也没关系，APP 能正常运行，只是图片位置显示空白或裂图。项目里没有自带这些图片，需要你自己准备。

### 5.3 启动 Tomcat

1. 进入 Tomcat 的 `bin` 目录
2. 双击 `startup.bat`
3. 弹出一个黑窗口，等它输出完，不要关闭
4. 浏览器访问 `http://localhost:8085`，能看到 Tomcat 欢迎页就成功了

## 六、启动前端APP

### 6.1 用 DevEco Studio 打开项目

1. 打开 DevEco Studio
2. 欢迎页点 "Open"（或顶部菜单 File → Open）
3. 选择前端项目目录：`D:\lg\project\archive\medicine-query-system\frontend`
4. 点 "OK"，等待项目加载和索引完成（右下角有进度条）

### 6.2 修改前端请求地址（非常重要！）

前端代码里写的请求地址是 `http://localhost:8082`，但在**模拟器**里，`localhost` 指的是模拟器自己，不是你的电脑。所以必须改成你电脑的 IP 地址。

**第一步：查看你电脑的 IP 地址**
1. 打开 cmd，输入：
   ```
   ipconfig
   ```
2. 找到你当前在用的网卡（一般是 "无线局域网适配器 WLAN" 或 "以太网适配器 以太网"）
3. 记下 `IPv4 地址`，比如 `192.168.1.100`

**第二步：修改前端代码**

需要修改两个文件：

1. 打开 `frontend/entry/src/main/ets/pages/Index.ets`
   - 找到第102行左右：
     ```typescript
     "http://localhost:8082/med/selectMedByName?mname=" + mname,
     ```
   - 把 `localhost` 改成你电脑的 IP，比如：
     ```typescript
     "http://192.168.1.100:8082/med/selectMedByName?mname=" + mname,
     ```

2. 打开 `frontend/entry/src/main/ets/pages/Detail.ets`
   - 找到第86行左右：
     ```typescript
     "http://localhost:8082/med/selectMedByMid?mid=" + mid,
     ```
   - 同样把 `localhost` 改成你电脑的 IP

3. 保存两个文件（Ctrl + S）

> **注意**：如果你电脑的 IP 是动态分配的（每次连网可能变），每次跑之前最好确认一下 IP 有没有变，变了就要改代码。

### 6.3 配置网络权限（如果需要）

HarmonyOS APP 访问网络需要声明权限。检查 `frontend/entry/src/main/module.json5`，确保里面有网络权限声明。如果没有，在 `module` 里加上：
```json
"requestPermissions": [
  { "name": "ohos.permission.INTERNET" }
]
```

### 6.4 启动模拟器并运行

1. 在 DevEco Studio 顶部工具栏，找到设备选择下拉框（一般显示 "No Device" 或某个设备名）
2. 点下拉框 → 选你之前创建的模拟器（比如 "Mate 60"）
3. 点旁边的绿色三角运行按钮（或按 Shift + F10）
4. 等待模拟器启动并安装 APP（第一次可能要等几分钟）
5. APP 启动后，你会看到首页：顶部轮播图，下面一个搜索框

## 七、走一遍核心流程

现在三个服务都跑起来了：
- ✅ MySQL 数据库（3308端口）
- ✅ 后端 Java 服务（8082端口）
- ✅ 前端 APP（模拟器里）
- ⚪ 图片服务（8085端口，可选）

### 第一步：搜索药品

1. 在 APP 首页的搜索框里，输入一个药品英文名，比如：
   ```
   Paracetamol
   ```
   （对乙酰氨基酚，扑热息痛）

   > 数据库里的药名都是英文的，比如：Paracetamol、Ibuprofen、Aspirin、Amoxicillin、Omeprazole 等。输入中文搜不到。

2. 点搜索框右边的 **"搜索"** 按钮

3. 搜索框下方会出现药品列表，每一行显示：
   - 左边：药品图片（如果图片服务没启动，这里是空的）
   - 中间：药名、单价
   - 右边："详情"按钮

### 第二步：查看药品详情

1. 在搜索结果里，点任意一个药品右边的 **"详情"** 按钮
2. 跳转到详情页，显示该药品的完整信息：
   - 药品大图（顶部）
   - 药品名称
   - 药品单价
   - 保质期
   - 药品用量（怎么吃）
   - 药效（治什么）

### 第三步：试试搜索不存在的药

1. 回到首页（点模拟器的返回键）
2. 在搜索框输入一个不存在的药名，比如：
   ```
   xxxxx
   ```
3. 点搜索
4. 列表不会显示任何内容（后端返回了"无此相关药品！"的错误，前端清空了列表）

### 第四步：不输入直接搜索

1. 清空搜索框
2. 直接点搜索
3. 同样不会显示结果（后端返回"请输入药品名！"）

## 八、常见问题排查

### Q1：后端启动报错，连不上数据库

**现象**：`mvn spring-boot:run` 启动时报错，有 `Communications link failure` 或 `Access denied`

**解决**：
1. 确认 MySQL 服务已经启动：打开 cmd 输入 `services.msc`，找到 MySQL 服务，看状态是不是"正在运行"
2. 确认端口号：`application.properties` 里的端口（默认3308）和你 MySQL 实际端口一致
3. 确认用户名密码：`root` / `123` 和你设置的一致
4. 确认数据库 `medicinesystem` 已经创建

### Q2：浏览器访问后端接口正常，但 APP 搜不到东西

**现象**：浏览器访问 `http://localhost:8082/med/selectMedByName?mname=Aspirin` 有数据，但 APP 里搜索没反应

**解决**：
1. 前端代码里的 `localhost` 有没有改成你电脑的 IP？（见 6.2 节，这是最常见的原因）
2. 电脑和模拟器是否在同一网络？用本地模拟器一般没问题
3. 电脑防火墙有没有拦截 8082 端口？可以临时关闭防火墙试试
4. 看 DevEco Studio 底部的 "Log" 窗口，有没有报错信息

### Q3：APP 里图片不显示

**现象**：搜索结果有文字，但图片位置是空的或裂图

**解决**：
1. Tomcat 图片服务有没有启动？（见第五章）
2. Tomcat 端口是不是 8085？
3. `webapps/medicineImages/` 目录下有没有对应的图片文件？
4. 数据库里 `mimage` 字段的地址是 `http://localhost:8085/medicineImages/xxx.png`，在模拟器里 `localhost` 也需要改成电脑 IP。可以修改数据库里的 mimage 字段，或者用 SQL 批量替换：
   ```sql
   UPDATE medicine SET mimage = REPLACE(mimage, 'localhost', '192.168.1.100');
   ```
   （把 IP 换成你电脑的实际 IP）

### Q4：Maven 下载依赖很慢或失败

**现象**：`mvn clean compile` 卡在下载，或者报错 `Could not transfer artifact`

**解决**：配置 Maven 国内镜像源
1. 打开 Maven 目录下的 `conf/settings.xml`
2. 找到 `<mirrors>` 标签，在里面加：
   ```xml
   <mirror>
     <id>aliyunmaven</id>
     <mirrorOf>*</mirrorOf>
     <name>阿里云公共仓库</name>
     <url>https://maven.aliyun.com/repository/public</url>
   </mirror>
   ```
3. 保存后重新执行 `mvn clean compile`

### Q5：DevEco Studio 打开项目报一堆红色错误

**现象**：代码里全是红线，运行按钮是灰的

**解决**：
1. 等待右下角的索引进度条走完，刚打开项目需要时间
2. 顶部菜单 Build → Clean Project，然后 Build → Rebuild Project
3. 检查 SDK 是否安装正确：File → Project Structure → Project，看 SDK 路径
4. 点顶部的 "Sync Project with Gradle Files" 按钮（如果有的话）

### Q6：怎么停止后端？

在运行后端的那个 cmd 窗口里，按 `Ctrl + C`，然后输入 `Y` 回车。

### Q7：怎么重新启动后端？

关闭后重新打开 cmd，进入 backend 目录，再执行 `mvn spring-boot:run`。

## 九、项目接口说明（给想了解原理的人）

后端提供两个接口：

### 1. 按名称查询药品
- **地址**：`http://localhost:8082/med/selectMedByName`
- **方法**：GET 或 POST
- **参数**：`mname`（药品名称）
- **示例**：`http://localhost:8082/med/selectMedByName?mname=Aspirin`
- **返回**：
  ```json
  {
    "status": true,
    "message": "",
    "list": [
      {"mid":"9","mname":"Aspirin","price":9.9,"mImage":"http://..."}
    ]
  }
  ```

### 2. 按ID查询药品详情
- **地址**：`http://localhost:8082/med/selectMedByMid`
- **方法**：GET 或 POST
- **参数**：`mid`（药品ID）
- **示例**：`http://localhost:8082/med/selectMedByMid?mid=9`
- **返回**：
  ```json
  {
    "status": true,
    "message": "",
    "object": {
      "mid":"9","mname":"Aspirin","price":9.9,"valid":30,
      "eatNum":"必要时1片，温水送服","handle":"止痛、消炎...",
      "mImage":"http://..."
    }
  }
  ```
